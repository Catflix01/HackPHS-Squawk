# Required cockpit loop audio files

Add these files to this folder before demoing the full cockpit soundscape:

- `engine.mp3` — looping propeller/engine sound
- `wind.mp3` — looping cockpit wind noise

Recommended specs:

- Length: **30-60 seconds** each
- Format: **MP3**, seamless loop (no abrupt start/end clicks)
- Loudness: normalized so both loops can blend together
